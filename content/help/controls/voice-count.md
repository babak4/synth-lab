**What it does.** Sets the most notes that can sound at once. When you play more, the oldest note is stolen (notes already fading out go first).

**Range.** 1 to 8. It starts at 8.

**Tip.** A long release uses voices fast, because each fading note still counts. If notes cut off, raise the voice count or shorten the release.
