**What it does.** Chooses the shape of oscillator B's wave, which sets its basic tone. It starts switched off, so you can add it when you want a second voice.

**Range.** Sine, triangle, sawtooth, square or pulse, plus Off. They run from the softest (a sine is a single [harmonic](term:harmonic)) to the brightest (a sawtooth has them all).

**Tip.** Change the shape while holding a note and watch the [spectrum](term:spectrum). Each [waveform](term:waveform) has its own pattern of harmonics.
