title: Oscillator A pulse width
kind: control
related: [oscillators, osc-a-waveform, lfo-destination]
presets: [pwm-strings]
---
**What it does.** Changes the width of oscillator A's [pulse](term:pulse) wave: how much of each cycle it spends high. It only has an effect when the waveform is set to pulse.

**Range.** 5% to 95%. At 50% the pulse is a [square](term:square) wave.

**Tip.** Set the LFO destination to pulse width and let it sweep this slowly for a lively, string-like sound.
